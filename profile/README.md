## Overview

NextCore의 소스코드, 개발 문서와 브랜드 리소스를 위한 공간이다.

코드와 문서는 구현 현황을 기준으로 정리한다. 설치 방법, 지원 환경과 릴리스별 변경 사항은 각 코드 저장소의 문서를 기준으로 확인한다.

## Identity

분홍색 심벌과 짙은 색 워드마크로 구성된 아이덴티티를 사용한다. 위 이미지는 기본 로고, 축소 적용 예시와 어두운 인터페이스 적용 예시를 담은 원본 브랜드 보드다.
